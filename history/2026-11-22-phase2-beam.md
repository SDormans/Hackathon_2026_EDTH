# Phase 2 beam-search benchmark summary, 2026-11-22

Summary of the `test_logger.py` runs for the Phase 2 beam changes. It replaces their raw `history/` folders. Every run used:

```sh
python3 test_logger.py --workers 1 --seconds 45 --levels L1,L2,L3,L4 --seeds <0-2,15-20 | 30-45> [--planner <worktree>/planner.py]
```

Each run used `--workers 1`, but several runs shared one 8-CPU machine at the same time. Runs with the same batch label ran together: batch 1 had 4 runs, batch 2 had 7, batch 3 had 5, batches 4 and 5 had 6. The final `phase2-heldout` run (batch F) ran alone. Candidate code ran from separate worktrees. Scores are official raw scores. A failed or invalid plan would count as 0. Slowest is the slowest full planner process in the run, in seconds.

**Outranked (beam-cut)** counts unserved contacts whose primary reason is `outranked`. The number in brackets is how many of those had at least one valid serving child cut by the beam width (`beam_pruned` > 0, added in Step 0).
