# Phase 3 LNS benchmark summary, 2026-11-22

Summary of the `test_logger.py` runs for the Phase 3 LNS changes. Raw run folders are not committed (3–6 MB each). Command for every run:

```sh
# tuning: 36 cases
python3 test_logger.py --workers 1 --seconds 45 --levels L1,L2,L3,L4 --seeds 0-2,15-20 [--planner <worktree>/<wrapper>.py]
# held-out: 64 cases, note "phase3-heldout ..."
python3 test_logger.py --workers 1 --seconds 45 --levels L1,L2,L3,L4 --seeds 30-45 [--planner <worktree>/<wrapper>.py]
```

Runs in the same group ran at the same time on one 8-CPU machine, one worktree each; compare only within a group. Each `lns_share` candidate was a wrapper that appends `--lns-share` to `planner.py`. Scores are official raw scores. Every plan in every run was valid. "Slowest" is the slowest planner process.
