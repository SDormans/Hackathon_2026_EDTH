# The live validation board

A board that updates while you work, so you can see how your planner compares. You upload **plans** (not code) for a fixed set of public scenarios; the organisers' server validates and scores each one with the same validator and scorer as `fleetkit score`, and ranks the teams.

**This is not the final ranking.** The final ranking runs your hand-in on scenarios you have not seen. The board is a validation set: you can tune to it, and the final shows whether that carried over.

## The scenarios

Eight public scenarios, regenerated by the public generator: `L1-101, L2-201, L2-202, L3-301, L3-302, L3-303, L4-401, L4-402`.

```sh
python3 -m fleetkit validation-set -o validation      # writes the eight scenario files
```

## Send a plan

Your organisers give you the server address, your team name and a token. Save them once:

```sh
python3 -m fleetkit board-login --server http://<address>:8080 --team "Your team" --token <token>
```

Then, for one scenario or for a whole folder (plans named `L1-101.json`, `L2-201.json`, ...):

```sh
python3 -m fleetkit submit L3-301 plan.json
python3 -m fleetkit submit-all my-plans/
```

`submit` first checks your plan with the local validator and does not send one that is invalid (`--force` sends it anyway, to see what the server says). The server keeps your **best** score per scenario, so a worse plan never hurts you. Wait a couple of seconds between submissions; the client does it for you.

## What the board shows

- Per team: the sum of your best scores per level (L1 to L4), the total, the total against the shipped greedy baseline ("× base"), and how many of the eight scenarios you have a plan for.
- A feed of the latest improvements.
- Ties go to the team that reached the score first.

Open the address in a browser. Teams see each other's scores, never each other's plans.

## What it does not prove

A plan can come from any process, including hours of computing. The final evaluation runs your planner with its 60 seconds per scenario. The board only says which plans are valid and how good they are.
